## 1. Create `Sources/Vibenotch/Model/NotchGeometry.swift`
A pure, dependency-free enum with static functions (no AppKit types beyond CGRect/CGFloat so they're unit-testable without a screen):

```swift
import CoreGraphics

enum NotchGeometry {
    /// The physical notch cutout rect from a screen's auxiliary areas.
    /// Returns nil when there is no notch (no valid aux gap).
    static func notchRect(auxLeftMaxX: CGFloat?, auxRightMinX: CGFloat?,
                          frameMaxY: CGFloat, safeTop: CGFloat) -> CGRect?

    /// Widened trigger zone covering the visible peek beside the cutout.
    static func hitRect(from notchRect: CGRect, sideMargin: CGFloat, bottomExtra: CGFloat) -> CGRect

    /// Fallback centered rect when there is no notch.
    static func fallbackRect(frameMidX: CGFloat, frameMaxY: CGFloat, visibleMaxY: CGFloat,
                             width: CGFloat) -> CGRect

    /// Expanded-content hit region (for keeping the panel open while the pointer is over it).
    static func expandedContentRect(frameMidX: CGFloat, frameMaxY: CGFloat,
                                    notchHeight: CGFloat, width: CGFloat, height: CGFloat) -> CGRect
}
```
Move the exact math currently inlined in `HoverController.notchRect(on:)`, the `hitRect` computation in `pin(to:)`, and `NotchWindowManager.containsExpandedContent(at:)` into these pure functions, preserving values exactly (sideMargin 150, bottomExtra 16; expanded width 370, height 230+notchHeight, etc.).
